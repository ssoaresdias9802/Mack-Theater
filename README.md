## 🚀 Overview

The **Mack Theater System** is a console-based application designed to simulate a real-world theater environment, focusing on **ticket sales, client management, and event organization**.

This project demonstrates the ability to design and implement a structured system using **Object-Oriented Programming**, emphasizing clean logic, user interaction, and modular organization.

---

## 🎯 Key Highlights

* Structured using **OOP principles** (separation of responsibilities)
* Interactive **menu-driven system**
* Realistic simulation of **ticket purchasing workflow**
* Clean and scalable code organization
* Focus on **readability and maintainability**

---

## ⚙️ Core Features

* 🎭 **Show Management**
  Register events with name, date, time, and pricing

* 👤 **Client Management**
  Store and manage client data using CPF

* 🎟️ **Ticket Sales**
  Simulate ticket purchasing with validation of available data

* 🖥️ **Interactive CLI**
  User-friendly console interface with input validation

---

## 🧠 Technical Skills Demonstrated

* Object-Oriented Programming (OOP)
* Java Collections (`ArrayList`)
* Input handling with `Scanner`
* Control flow (loops, conditionals, validation)
* Modular code design
